# seeds.hues.flowers v2 — Design

## 1. Stack (exact pins live in `package.json`)
Next.js 16.4.x · React 19.3 · TypeScript strict · Tailwind 4 · Drizzle ORM (SQLite/D1) ·
Zod 4 · `@opennextjs/cloudflare` · Wrangler 4 · Vitest · Playwright.

## 2. Structure
```
app/                     App Router (pages, route handlers, manifest, sitemap, robots, llms.txt)
  api/v1/**              public API route handlers (thin; call lib/api + lib/services)
  api/revalidate         token-protected revalidation (internal)
  api/track              click beacon (internal)
  og/[kind]/[slug]       generated OG cards (ImageResponse)
components/{layout,ui,search,variety,seller,seo}
lib/db                   schema.ts, client.ts (the ONLY place env.DB is read)
lib/repositories         ONLY layer importing Drizzle; atomic.ts (ONLY db.batch); fts.ts (ONLY raw FTS SQL)
lib/services             business logic shared by Server Components and API
lib/validators           Zod schemas: DB rows + API contract (single source of truth)
lib/api                  envelope, errors, cursor, ETag, CORS, rate limit, route wrapper
lib/seo                  metadata + JSON-LD builders
lib/catalog              importer core (validation, assertions, content level), snapshot allowlist
migrations/              D1 SQL migrations (drizzle-kit generated + custom FTS migration)
scripts/                 import-catalog.ts, publish-catalog.ts, gen-icons.ts, build-sw.ts, warm-crawl.ts
public/                  sw.js, icons
tests/unit, tests/contract, tests/e2e
```

## 3. Data model
Core tables (old §3.1) + FINAL §2 additions: `sources`, `variety_aliases`,
`import_batches`, `match_queue`, `price_history`, `catalog_publish`, `media` (empty),
`outbound_clicks`; `sellers.provenance/listing_policy/platform`;
`varieties.content_level/indexable/protection/protection_note/source_id`;
`listings.source_id`. Stubs: `users`, `seller_accounts`, `reviews`.
Integer PKs internally, slugs publicly. Integer cents. Booleans via Drizzle boolean mode.
Timestamps ISO text.

FTS: `varieties_fts` (FTS5, `tokenize='trigram'`) with columns variety name, plant common
name, Latin name, description, tags, aliases; kept in sync by triggers on `varieties`,
`plants`, `variety_tags`, `variety_aliases`. `searchVarieties(q)` is the only reader;
queries shorter than 3 characters use a lower-cased prefix match instead (trigram cannot
match < 3 chars). No typo-tolerance claims.

## 4. Data access
- `createDb(d1)` → Drizzle client; `getDb()` reads `getCloudflareContext({async:true}).env.DB` per request.
- Repositories are pure functions of `db`; outputs parsed by Zod (fail loudly).
- `atomic(db, ops)` wraps `db.batch()` — D1 batches are all-or-nothing; the Postgres port becomes `db.transaction()`.
- Multi-row inserts chunked to ≤ 100 bound parameters (D1 limit).
- `listing_policy` enforced in the repository mapping: `removed` hides the seller and its listings; `no_prices` nulls prices.

## 5. Services and API (X2)
`createServices(db)` returns `varieties`, `sellers`, `plants`, `categories`, `search`,
`catalog`. Server Components call `getServices()` in-process; `/api/v1` handlers call the
same functions and wrap the output in the envelope. Contract tests assert the API `data`
deep-equals the service output.

API wrapper (`lib/api/route.ts`): rate limit (Workers `ratelimits` binding, per-isolate
token bucket fallback) → method check (405) → handler → envelope → ETag (SHA-256 of body)
→ 304 → headers (`Cache-Control`, `X-API-Version: 1`, `X-Robots-Tag: noindex`, CORS
allowlist with `Vary: Origin`). Cursor = base64url JSON `{o, f}` where `f` fingerprints the
query; mismatched cursor → 400.

## 6. Rendering
- Detail routes: `generateStaticParams` → `[]`, `dynamicParams = true`, `revalidate = 86400`, ISR on first hit (OpenNext R2 incremental cache + D1 tag cache + memory queue). Nothing reads D1 at build time.
- List routes read `?page=` and render dynamically (24 per page).
- `/search` SSR, `noindex, follow`, canonical `/search`.
- Legacy `?v=`/`?s=` → `permanentRedirect()` (308) from the list pages.

## 7. SEO
`lib/seo/metadata.ts` builds titles/descriptions/canonicals; `lib/seo/jsonld.ts` builds
JSON-LD with a prohibited-key guard (`FAQPage`, `AggregateRating`, `Review`,
`priceValidUntil` throw). OG cards at `/og/{variety|seller|plant|site}/{slug}` (1200×630
PNG). Sitemap from DB (indexable only), robots allow-all, `llms.txt` from DB + config.

## 8. PWA
`app/manifest.ts`; icons generated by `scripts/gen-icons.ts` (pure Node PNG encoder);
`public/sw.js` generated from `scripts/sw.template.js` with a build version. Install:
precache `/`, `/offline`, icons and the static assets referenced by `/offline`, then
`skipWaiting()`. Activate: delete old caches, `clients.claim()`. Client: on
`controllerchange` reload once; check for updates on load and on visibility change.

## 9. Measurement
Outbound links keep direct hrefs; `navigator.sendBeacon('/api/track')` writes
`outbound_clicks` (D1 table, no cookies). Cloudflare Web Analytics script only when
`NEXT_PUBLIC_CF_ANALYTICS_TOKEN` is set.
